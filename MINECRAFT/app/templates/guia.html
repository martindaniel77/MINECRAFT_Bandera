GUÍA DE APRENDIZAJE PARA ESTUDIANTES

Aprender ciberseguridad debe ser claro, estructurado y sin frustración. Aquí tienes los conceptos fundamentales de cada desafío organizados para que comprendas la lógica de cada vulnerabilidad antes de atacarla.

🚩

1. ¿Qué es una Bandera (Flag) y cómo se entrega?

En una competencia de ciberseguridad (CTF), tu meta como estudiante atacante es encontrar un "secreto" oculto dentro del sistema vulnerable. A este secreto se le llama Bandera o Flag.

Formato oficial en esta plataforma: Flag{MINECRAFT_...} o en mayúsculas FLAG{...}

Cuando encuentres una bandera en el código fuente, en una imagen o tras explotar una vulnerabilidad, cópiala exactamente e ingrésala en la caja de validación del desafío para ganar puntos de experiencia (XP) y sumar el ítem a tu inventario.

💉

2. ¿Qué es una Inyección SQL y cómo funciona ' OR 1=1 --?

Una aplicación web interactúa con la base de datos mediante sentencias SQL. Por ejemplo, al buscar un cofre: 

SELECT * FROM cofres WHERE nombre LIKE '%TU_BUSQUEDA%' AND bloqueado = 0;

Si la aplicación concatena lo que escribes directamente sin sanitizarlo, puedes inyectar comandos SQL:

1. La comilla simple ': Cierra el texto esperado por la base de datos y te permite agregar sentencias.
2. El operador OR 1=1: Como 1 siempre es igual a 1 (Verdadero), la condición se vuelve cierta para todos los registros del juego, incluso los cofres ocultos.
3. Los guiones --: Le dicen a SQLite que ignore el resto de la consulta original, anulando el filtro AND bloqueado = 0.
🔍

3. ¿Cómo encontrar secretos ocultos en imágenes y archivos?

Los archivos digitales no solo contienen píxeles o texto visible, también almacenan metadatos (información sobre el autor, software, comentarios) y pueden ocultar mensajes:

  • Inspección de Metadatos: En Kali Linux puedes usar exiftool mapa_cueva.png para leer comentarios y propiedades ocultas.
  • Extracción de Texto: El comando strings archivo.png busca cadenas de caracteres legibles dentro de archivos binarios.
  • Decodificación Base64: Si ves un texto que termina en = o parece letras y números aleatorios (ej: U1lOVHs...), decodifícalo con: 
    echo "TEXTO_BASE64" | base64 -d
  • Cifrado César / ROT-13: Es un cifrado donde cada letra se desplaza 13 posiciones en el abecedario. Se decodifica con: 
    echo "TEXTO" | tr 'A-Za-z' 'N-ZA-Mn-za-m'
🍪

4. ¿Qué es XSS (Cross-Site Scripting) y para qué sirve?

Ocurre cuando una aplicación web permite que un usuario ingrese código HTML/JavaScript malicioso y luego lo renderiza en pantalla ante otros usuarios (o ante un bot auditor, como el Piglin Guard).

Cuando el administrador abre la página infectada, el script se ejecuta en su navegador con todos sus permisos, permitiendo leer su cookie de sesión: 

<script>fetch('/nether/gold/leak?cookie=' + encodeURIComponent(document.cookie));</script>
📂

5. Salto de Directorios (Path Traversal / LFI)

Si un servidor web te permite pedir un archivo mediante un parámetro (ej: ?altar_file=documento.txt), un atacante puede usar ../ para subir niveles en el árbol de carpetas del servidor y leer archivos protegidos: 

../../root/real_dragon_egg.txt

Esto permite burlar trampas (Honeypots) colocadas intencionalmente en carpetas públicas.

💡

6. Método de Aprendizaje Recomendado

  1. Comienza por el Overworld: Es la dimensión introductoria diseñada para que entiendas la dinámica sin agobiarte.
  2. Usa el botón "Ver Código": En cada reto puedes inspeccionar el código fuente vulnerable para entender dónde está el error de programación.
  3. Consulta las Pistas: Si te quedas atascado, puedes desbloquear pistas conceptuales usando la XP que acumulas.
  4. Pregunta e investiga: Cada reto representa un fallo real que los desarrolladores cometen en el mundo laboral.
