GUÍA DE APRENDIZAJE PARA ESTUDIANTES

Aprender ciberseguridad debe ser claro, estructurado y sin frustración. Esta guía explica los conceptos de cada bandera, herramientas útiles y curiosidades. No es una solución paso a paso: la idea es que investigues y practiques.

🚩

0. ¿Qué es una Bandera (Flag)?

Concepto: En un CTF, la bandera es el secreto que demuestra que comprometiste el reto. Al ingresarla correctamente ganas XP y sumas el ítem a tu inventario.

Formato oficial: Flag{MINECRAFT_...} o en mayúsculas FLAG{...}

Tema: Concepto general de CTF (Capture The Flag).

Herramientas: Navegador, terminal de Kali Linux, editor de texto.

Curiosidad: Las flags nacieron en los primeros CTF académicos (UCSB iCTF, 2003) para verificar automáticamente quién había comprometido un servicio.

1. Bandera — Lingote de Hierro: Esteganografía, Base64 y César

Concepto: La flag está oculta en los metadatos de una imagen. Debes extraerla, decodificar una capa de transporte y deshacer un cifrado clásico.

Tema: Esteganografía en metadatos + codificación Base64 + cifrado César (ROT-13).

Explicación: Los archivos PNG pueden contener campos de texto (metadatos) que no se ven en la imagen. El secreto se envuelve en Base64 y se cifra con un desplazamiento de 13 posiciones.

Herramientas y comandos de ejemplo:

# Inspeccionar metadatos de una imagen:
exiftool imagen.png

# Decodificar Base64:
echo "TEXTO_BASE64" | base64 -d

# Aplicar ROT-13:
echo "TEXTO" | tr 'A-Za-z' 'N-ZA-Mn-za-m'
Curiosidad: El cifrado César debe su nombre a Julio César. ROT-13 es un caso particular con desplazamiento 13. Los metadatos han filtrado información sensible en casos reales (autor, software, rutas).

2. Bandera — Diamante: Inyección SQL (SQLi)

Concepto: El buscador de cofres concatena tu entrada directamente en la consulta SQL. Aprovechando eso puedes ver registros que deberían estar bloqueados.

Tema: SQL Injection (SQLi).

Explicación: La comilla simple cierra el texto esperado, OR 1=1 hace verdadera la condición para todos los registros y -- comenta el resto de la consulta, anulando filtros como AND bloqueado = 0.

Ejemplos de SQLi (para practicar):

# Bypass de login / filtro:
' OR 1=1 --
' OR '1'='1
admin' --

# Union-based (conceptual):
' UNION SELECT NULL, NULL --

# Time-based (conceptual):
' OR SLEEP(5) --

# Herramientas: sqlmap, Burp Suite, navegador.
Curiosidad: La primera SQLi masiva se reportó en 1998. Hoy sigue siendo el riesgo #1 del OWASP Top 10. La defensa es usar consultas parametrizadas.

3. Bandera — Consola de las Cuevas: Enumeración y allowlist

Concepto: Una terminal restringida permite enumerar rutas y leer archivos para encontrar la llave de ignición del portal.

Tema: Enumeración de rutas y validación por allowlist.

Explicación: La consola solo acepta una lista cerrada de comandos (ls, cat, help, clear) y resuelve rutas contra un diccionario. No es una shell real.

Herramientas y comandos de ejemplo:

# Enumerar:
ls
ls /cueva/

# Leer archivos:
cat /cueva//

# Ayuda:
help
Curiosidad: Una consola que valida por allowlist solo ejecuta lo que está en la lista. Las listas negras fallan porque siempre aparece un comando nuevo que nadie prohibió.

4. Bandera — Lingote de Oro: Stored XSS y robo de cookies

Concepto: Inyectas código JavaScript en una nota pública. Otro usuario (el Piglin Guard) la ejecuta en su navegador con sus permisos, permitiendo robar su sesión.

Tema: Stored XSS y robo de cookies de sesión.

Explicación: El tablón muestra la nota sin escaparla. El navegador del Guard interpreta el script y puede enviar la cookie a un endpoint del servidor.

Más ejemplos de script (XSS):

<script>alert(1)</script>
<script>console.log('XSS')</script>
<img src=x onerror=alert(1)>
<svg onload=alert(1)>
<body onload=alert(1)>
<a href="javascript:alert(1)">haz clic</a>
<iframe src="javascript:alert(1)"></iframe>

# Robo de cookies (conceptual):
<script>fetch('/endpoint?cookie=' + encodeURIComponent(document.cookie));</script>
Curiosidad: El worm "Samy" en MySpace (2005) infectó a más de un millón de perfiles en una hora usando XSS almacenado. La defensa es escapar/validar la entrada y usar CSP.

5. Bandera — Vara de Blaze: Subida de archivos a RCE

Concepto: Un formulario permite subir archivos y además ejecutarlos. Sin validación de extensión ni contenido, puedes subir código malicioso.

Tema: Unrestricted File Upload → ejecución remota de código (RCE).

Explicación: El servidor guarda el archivo con el nombre y tipo que tú indicas y ofrece una forma de ejecutarlo. Un script en Python puede leer archivos del servidor.

Comandos para crear la carpeta/archivo desde la terminal:

# Crear una carpeta de trabajo:
mkdir -p ~/ctf/blaze && cd ~/ctf/blaze

# Crear el script con un editor:
nano receta.py
# o con echo:
echo "print(open('/ruta/del/archivo').read())" > receta.py

# Ver el contenido:
cat receta.py
ls -la
Curiosidad: La falta de validación de extensiones es la causa de muchos incidentes reales: un formulario de "subir avatar" que termina ejecutando un webshell. La defensa es validar extensión, MIME y contenido.

6. Bandera — Ojo de Ender: Violación de mínimo privilegio

Concepto: El servidor decide tu rol a partir de un dato que tú mismo envías (parámetro o cookie). Si lo modificas, puedes obtener privilegios que no te corresponden.

Tema: Broken Access Control / parameter tampering.

Explicación: Esto se conoce como "decide by client": el cliente puede mentir sobre su identidad o rol. En la práctica, cambiar un parámetro en la URL o en una cookie ha dado acceso de administrador.

Flujo de carpetas en la terminal:

# Ver dónde estás:
pwd

# Listar contenido:
ls -la

# Entrar a una carpeta:
cd nombre_carpeta

# Subir un nivel:
cd ..

# Buscar archivos:
find . -name "*.txt"

# Leer un archivo:
cat archivo.txt

# (La idea es inspeccionar el sistema de archivos y entender cómo se organizan los recursos.)
Curiosidad: Cambiar un parámetro en la URL o en una cookie ha dado acceso de administrador en sistemas reales (IDOR / broken access control). La defensa es validar permisos en el servidor.

7. Bandera — Cristales del End: Explotación de servicio y backdoor

Concepto: Un servicio interno tiene una puerta atrás (backdoor) que compara tu entrada contra un token fijo y, si coincide, ejecuta comandos.

Tema: Explotación de servicio / backdoor (CVE simulado).

Explicación: Estas backdoors casi nunca se aleatorizan: comparan tu entrada contra un token fijo. El proveedor y el año suelen estar escritos en el propio token.

Más ejemplos de exploit (incluye el necesario):

# Payloads de ejemplo para servicios con backdoor:
CVE-2026-OVERLOAD;shatter_crystals
AB;shatter_crystals
OVERLOAD_CRYSTALS

# Concatenación de comandos (conceptual):
valor; ls
valor && whoami
valor | cat /etc/passwd

# Otros triggers comunes:
shatter_crystals
CVE-2026-OVERLOAD
Curiosidad: Backdoors reales se han escondido en software legítimo (servidores IRC, compiladores) y se activaban con una secuencia exacta de bytes.

8. Bandera — Ender Dragón: Inyección de comandos (Command Injection)

Concepto: Tu entrada se inserta dentro de una línea que se ejecuta en una shell. Si terminas el comando antes, la shell interpreta el resto como una orden nueva.

Tema: Command Injection.

Explicación: La shell no sabe dónde acaba tu dato. Usando metacaracteres como ;, && o | puedes ejecutar comandos adicionales.

Comando inicial (ejemplo):

# Comando inicial para empezar la inyección:
100; cat /secret/dragon_slain.txt

# Variantes:
100 && cat /secret/dragon_slain.txt
100 | cat /secret/dragon_slain.txt
Curiosidad: Shellshock (CVE-2014-6271) permitió ejecutar comandos arbitrarios en millones de servidores Linux y dispositivos IoT. La defensa es evitar shell=True y validar/sanitizar la entrada.

9. Bandera — Huevo de Dragón: Enumeración de Active Directory con PowerView

Concepto: El Huevo está archivado en un dominio de Active Directory simulado (end.local). Debes enumerar usuarios, grupos, equipos y recursos compartidos para localizar el archivo del Huevo en el servidor de archivos.

Tema: Enumeración de Active Directory con PowerView.

Explicación: PowerView es una herramienta de auditoría de AD que permite listar objetos del dominio (usuarios, grupos, equipos, shares, sesiones). Las descripciones de cuentas de servicio suelen revelar recursos internos, y los shares pueden exponer archivos sensibles.

Comandos disponibles (consola PowerView):

Get-NetDomain
Get-NetDomainController
Get-NetUser
Get-NetUser -UserName 
Get-NetGroup
Get-NetGroupMember -GroupName ""
Get-NetComputer
Get-NetShare -ComputerName 
Find-DomainShare
Invoke-UserHunter
Get-Content \\\\SERVIDOR\\recurso\\archivo.txt
help
clear
Curiosidad: PowerView forma parte de PowerSploit y se usa en auditorías de Active Directory para enumerar usuarios, grupos, equipos, sesiones y shares. La defensa combina mínimo privilegio en los recursos compartidos, cuentas de servicio administradas (gMSA) y monitorización de consultas LDAP y SMB.

10. Método de Aprendizaje Recomendado

  1. Comienza por el Overworld: es la dimensión introductoria.
  2. Usa el botón "Ver Código": inspecciona el código vulnerable para entender dónde está el error.
  3. Consulta las Pistas: desbloquea pistas conceptuales usando la XP que acumulas.
  4. Lee la Guía por bandera: cada ítem te da el concepto y la curiosidad antes de atacar.
  5. Practica con las herramientas: usa los comandos de ejemplo como referencia, no como solución directa.
